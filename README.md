# RocketSearchProxy
This is a search proxy run by ultraviolet. All credits to TitaniumDev. The UI Is Made By Me Though.

# How To Run RocketSearch
## Method 1: Automatic/Script
Step 1. Run the script below
``` Shell
bash setup && bash run
```
Step 2.then set the port to public

Step 3. Go to the ports tab and click the globe icon in betwen the search icon and the clipboard.

Side Note: There will be a separate script called run. run this every time you want to use the proxy. only run the setup script the first time.
The command for the run script is below

``` Shell
bash run.sh
```
## Method 2: Manual
Step 1. Run the command below
``` Shell
cd Ultraviolet-app
```
Step 2. Then run this command to install Node Package Manager
``` Shell
npm install
```
Step 3. Now Run the proxy
``` Shell
npm start
```
Step 4. then set the port to public

Step 3. Go to the ports tab and click the globe icon in betwen the search icon and the clipboard.
